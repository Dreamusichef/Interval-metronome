How it works

• Both pads send MIDI note-on on the same input — routed to P1/P2 by note number.
• Calibrate plays 2 bars of 16th clicks; hit both pads in time with them (in unison is fine) to capture one shared latency offset, same as the main game's calibration principle.
• Run: each 16th-note slot must contain exactly one unconsumed hit from a player to count as 'clear'. Zero hits = drop, 2+ hits = cram — either ends that player's run.
• Run ends when both players are out, or after the configured number of bars if both survive.
